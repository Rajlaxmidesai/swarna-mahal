Swarna Mahal – Jewellery E-Commerce Website

Swarna Mahal is a full-stack jewellery e-commerce web application offering an elegant and user-friendly online shopping experience.

🚀 Features

•	Responsive homepage and jewellery product listings

•	User registration and login

•	Product management

•	Shopping cart and checkout

•	Order management

•	Admin dashboard

•	REST API integration

🛠️ Tech Stack

•	Frontend: React.js, Vite, CSS, Axios

•	Backend: Node.js, Express.js

•	Database: MongoDB Atlas

•	Authentication: JWT

Tools: Git, GitHub
